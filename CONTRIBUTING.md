# Contributing to Loft

Loft is source-available under the [PolyForm Noncommercial License 1.0.0](LICENSE.md). You are welcome to read the code, build it for yourself, and use it for any noncommercial purpose. Selling it, bundling it into a product, or using it inside a business needs a separate license; the Mac App Store edition covers that.

## Pull requests are not accepted

This is a one-person project and I keep the copyright on every line so the App Store edition stays possible. A pull request is closed automatically with a note pointing here. Nothing personal.

## What is welcome

- Bug reports: [open an issue](https://github.com/reneweteling/loft-app/issues/new?template=bug.yml). Say whether you run the GitHub build or the App Store edition, and paste the version from Settings, About.
- Feature ideas: [open an issue](https://github.com/reneweteling/loft-app/issues/new?template=feature.yml). Describe the situation you are in, not only the solution you have in mind.
- Questions: also an issue is fine.

Issues are read, and the useful ones get built. Credit goes in the release notes.

## Building from source

See the README. `./scripts/build.sh` produces an ad-hoc signed `build/Loft.app` for your own machine.
