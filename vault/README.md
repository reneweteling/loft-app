# Loft Vault

This folder is an **Obsidian vault**. Open it in Obsidian via *Open folder as vault* and point at `vault/`.

## Structure

```
vault/
├── 00-Index/         ← Maps of content (MOCs), start here
├── 10-Assets/        ← Image prompts, palette, asset checklist
├── 20-Setup/         ← Bucket setup, Gatekeeper, onboarding
├── 30-Architecture/  ← Design notes, pipelines, models
└── 40-Reference/     ← S3 gotchas, API notes, glossary
```

## Conventions

- Wikilinks only: `[[Page Name]]` — not markdown links
- Tags in frontmatter, not inline
- Filenames mirror page titles (`My Page.md` ↔ `# My Page`)
- Start exploring from [[Loft Overview]]
